This project introduces a class whose job is to manage a collection of other objects.The 'Garage' class holds a list of vehicle objects,demonstrating that a class's data can be more objects,not just plain numers or strings.
CONCEPTS PRACTICED
-A class attribute that is a list,initialized empty in '__innit__'
-Passing an entire object as an argument to another object's method
-Using '.append()' inside a method to grow an object's internal list
-Looping over a list of objects stored inside another objetc
-One class ('Garage') composed of multiple instances of another class ('Vehicle')-

The project can be tested,plug in real/made-up values and test the results for validation.
