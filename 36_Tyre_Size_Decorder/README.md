This program takes the values on the tyre of a road car ie tyre width,aspect ratio and diameter and calculates real tyre dimensions and tells us how wrong the speedemeter becomes if someone fits a different tyre size.

It takes in as inputs from the user,width,aspect ratio,diameter to calculate sidewall height,overall diameter,real speed as didplayed on the speedometer,percantage increase in diameter and issues out a warning if a reosonable threshold of 3% is exceeded.

The program also checks the user input validation and displays an error if the user does not enter the correct format or leaves a blank space.
