PROJECT :Tyre Size Calculator

OVERVIEW
-This Python project calculates important tyre dimensions from a standard tyre size.
-The User enters:
    *Tyre width
    *Aspect Ratio
    *Wheel Diameter

-The Program calculates:
    >Sidewall height (mm)
    >Overall tyre diameter (mm)
    >Rolling Radius (mm)
    >Tyre Circumfrence (mm)

ENGINEERING FORMULAE
1.SIDEWALL HEIGHT
sidewall height=(tyre width x Aspect Ratio) x 100
2.WHEEL DIAMETER
Wheel diameter (mm)=Wheel diameter(inches) x 25.4
3.OVERALL TYRE DIAMETER
Overall Diameter=Wheel Diameter + (2 x Sidewall Height)
4.ROLLING RADIUS
rolling radius=overall diameter/2
5.TYRE CIRCUMFRENCE
Circumfrence=pie x overall diameter
