This Python Project models the transfer of engine torque through a vehicle's drivetrain and calculates the resulting tractive force at the contact patch.
The Program demonstrates how transmission gearing,final drive ratio,drivetrain efficiency and tyre rolling radius influence the force available to accelerate a vehicle.
This is a simplified drivetrain model intended for automotive engineering analysis and educational purposes.

-The fundamental flow modelled by this program is:
    *Engine
    *Transmission Gearbox
    *Final drive/Differential
    *Driven wheels
    *Tyre (rolling radius)
    *Tyre (contact patch)
    *Tractive Force
    *Vehicle acceleration

-The following automotive engineering principles are applied to this program:
    #Engine torque
    #Transmission Gear Ratios
    #Final Drive Ratios
    #Drivetrain efficiency
    #Wheel Torque
    #Tyre rolling radius
    #Tractive force
    #Torque multiplication
    #Powertrain modelling

ASSUMPTIONS 
This model,however,takes into account several assumptions :
    -Constant engine torque
    -Consstant gear ratio
    -Constant Final drive ratio
    -Constant drivetrain efficiency
    -No tyre slip
    -No aerodynamic drag
    -No rolling resistance
    -No drivetrain inertia
    -No drivetrain losses separetelly modelled
    -Constant effective tyre rolling radius

Real world performance is far more complex because these quantitites can vary with operating conditions.
