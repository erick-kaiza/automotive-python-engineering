This project estimates a tire's sidewall height,overall diameter and contact patch area on the road,given tire size specifications and load/pressure inputs.It demonstrates chaining functions together by passing an unpacked return value from one function directly to another.

CONCEPTS PRACTICED
-Returning multiple values from a function via a tuple
-Unpacking a tuple into multiple named variables
-Passing an unpacked value from one function call as an input argument to a second function
