This project still builds around our previous concept except now I have introduced encapsulation,which is protecting an object's internal data using a naming convention and dedicated getter/setter rather than allowing direct access to raw attributes.

CONCEPTS PRACTICED
-The underscore convention ('_fuel_level_l') signals an attribute is intended for internal use,not direct access.
-Getter methods that provide safe,controlled read access
-Setter methods that validate input before changing internal state (rejecting negative values & capping excess values)
