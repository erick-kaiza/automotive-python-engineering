#Engine Performance Calculator

##OVERVIEW
This Python Project calculates engine power using engine torque and engine speed (RPM).
The program displays :
    -Engine Torque (Nm)
    -Engine Speed (RPM)
    -Engine Power (Horsepower)
    -Engine Power (Kilowatts)

###ENGINEERING FORMULA
Horsepower=(Torque x RPM)/7127
KIilowatts=Horsepower x 0.7457

#Example
Input
    -Torque=550(Nm)
    -Speed(RPM)=6500
    
Output
    -Horsepower : 501.6 HP
    -Engine Power: 374.1 kW
