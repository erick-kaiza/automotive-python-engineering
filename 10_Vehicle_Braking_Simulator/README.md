This Python Project simulates the braking performance of a vehicle using a real time-stepped numerical model.
The simulator calculates braking force from tyre-road friction and aerodynamic downforce,then continously updates vehicle velocity,braking distance amd braking time until the vehicle reaches zero speed.
This project builds upon concepts introduced in earlier projects,particularly vehicle dynamics,numerical simulation,tyre traction and aerodynamics.
Using enginnering inttuition the programme was tested under different conditions and has proven to be consistent from a Physics point of view,one can play with the values to validate this.
However,various assumptions were made and various factors excluded that affect real world vehicle braking performance eg:
    -constant coefficient of friction
    -constant vehicle mass
    -constant air density
    -instateneous tyre response
    -no weight transfer
    -all tyre grip available can be used for brakind etc
Therefore,this braking simulation is an educational vehicle-dynamics model rather than a complete braking simulation.
