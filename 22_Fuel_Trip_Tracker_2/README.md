This project extends the 'Vehicle' class with class-level attributes - data shared across every object of the class,as opposed to instance attributes,which are unique to each individual object.

CONCEPTS PRACTICED
-Defining a class attribute ('total_vehicles_created') outside methods to be shared in all instances.
-Updating a class attribute from inside the method using the class name,so that every new object contributes to one shared count.
-Accessing a class attribute via the class itself via any instance - both return the same shared value
-Mixing class attributes and instance attributes in the same method  

The programme is simply for practice and educational purposes.The working of the program can be tested to validate the results.
