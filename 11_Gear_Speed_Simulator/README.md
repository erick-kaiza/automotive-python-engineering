This Python program calculates vehicle speed at a given engine RPM for each gearbox ratio and determines the engine RPM after an upshift.
The project connects engine speed,gearbox ratios,final drive and tyre size to the resulting vehicle speed.

The gearbox changes the relationship between engine speed and wheel speed.A lower gear has a higher ratio,causing the wheels tp rotate more slowly relative to the engine while providing greater torque multiplication.One can place mock values to validate this claim using the program.

This is a simplified powertrain model intended to demonstrate the relationship between gearbox gearing,engine RPM and vehicle speed.Several assumptions have been made,including(but not limited to):
    -no clutch slip.
    -no tyre slip.
    -constant tyre diameter.
    -constant gear ratios.
    -no drivetrain losses.
