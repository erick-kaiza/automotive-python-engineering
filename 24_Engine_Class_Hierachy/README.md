This is my first inheritance-based project.A base 'Engine' class holds aspects shared by all engine types,while 'GasolineEngine' and 'DieselEngine' inherit from it and add their own special aspects
eg fuel octane rating and compression ratio

CONCEPTS PRACTICED
-Defining a parent/base class ('Engine')
-Creating child classes that inherit it from the parent.
-Adding new attribute/methods in a child class that the parent class doesn't have
-Inherited methods work automatically on child classes without being rewritten,since they were defined once on the parent.

KEY LESSON 
Inheritance avoids duplicating shared logic.
