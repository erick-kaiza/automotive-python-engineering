This project is a menu-driven python tool that estimates the number of load cycles a material can withstand before fatigue failure,using Basquil's equation - a fundamental relationship in mechanical fatigue analysis used to size components like crankshafts,axles and connecting rods.

This tool estimates cycles to failure for a given material and applied stress amptitide,then classifies the result into a standard fatigue regime.

The program uses real world physics used by mechanical / materials engineers during design and simulation,it can be tested for its validation

The project narrows the portfolio's focus toward powertrain materials analysis - understanding how cyclic loading during real-world operation governs component life , a core consideration in powertrain and performance engineering.
