#Fuel Consumption Calculator
##Overview

This Python Project calculates a vehicle's fuel economy and fuel consumption based on the distance travelled and the amount of fuel used.
It also estimates the total cost for the journey

##Engineering Claculations
Fuel Economy (km/L)=Distance /Fuel Used (L)
Fuel consumption=(Fuel Used /Distance) x 100
Fuel cost=Fuel Used x Fuel Price Per Litre

##Example
Input
Distance=200 km
Fuel Used=3L
Fuel Price=202 KES/L

Output
Fuel Economy=66.67km/L
Fuel Consumption=1.5L/km
Total Fuel Price:ksh 606.00
