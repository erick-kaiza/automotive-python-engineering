This project calculates how much concentrate vs water to mix for a target coolant ratio,given a total desired volume.Demonstrates default parameterv values by supporting both a standard 50/50 mix and a custom ratio.

CONCEPTS PRACTICED
-Default parameter values
-Returning multiple values from a function via a tuple
-Tuple unpacking
-Calling the same function two different ways
-f-strings with embedded newlines and formatted decimals
