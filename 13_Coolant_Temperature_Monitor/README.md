A command line tools that simulates monitoring engine coolant temperature and classifies each reading into an operating status zone,similar to warning logic behind ECU dashboard light.Runs a continous input loop,allowing repeated readings until the user exits.

FEATURES
Classifies coolant temperature into 'four' zones:Normal,high,critical & engine too cold.
Continous input loop for logging multiple readings in one session
Input validation via try/except
Exit on demand by typing 'q' to quit the program.

CONCEPTS PRACTICED
Functions with parameters
Multi-branch cinditional logic (if/elif)
While loops with 'break'
try/except for input validation
