A menu-driven Python tool that estimates bearing fatigue life using the industry-standard L10 life formula,same method used by manufacturers to rate wheel bearings,transmission bearings and differential bearings

L10 is the number of revolutions (or operating hours) that 90% of a batch of identical vearings will survive before exhibiting fatigue-related failure.It depends on the bearing's dynamic load rating,actual applied load and the bearing type (roller vs ball),since each type carries load differently

ENGINEERING CONTEXT
Bearing life prediction is a standard reliability calculation in powertrain and driveline design - used to validate that a bearing can survive the vehicle's expected life under real operating loads,without over-specigying the component.
