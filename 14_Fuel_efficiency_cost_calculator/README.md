A menu driven command-line tool for logging multiple vehicle trips and tracking fuel efficiency over time.Each trip is validated,stored and used to calculate both individual and overall average efficiency in km/L

Feature include:Interactive menu system,store multiple trips ina list,input validation via try/except,Calculate per-trip efficiency (km/L) and a running overall average across all trips,clean output f-strings 

Concepts practiced include:while loops with break,multiple except blocks for handling user errors,list of dictioneries,for loop with running totals,f-strings with formatted decimal output,distinguishing weighted averages from simple averages
