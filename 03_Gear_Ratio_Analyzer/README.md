#Gear Ratio Analyzer
##Overview

This Python project calculates wheel speed and vehicle wheel speed using engine RPM,transmission gear ratio,final drive ratio and tyre diameter.

It demonstrates how drivetrain ratios affect vehicle performance and speed,making it a useful tool for engineering students and enthusiasts.

###Engineering Concepts
This project applies the following automotive engineering principles:
    -Gear Ratio
    -Final Drive Ratio
    -Wheel Speed (RPM)
    -Tyre Circumfrence
    -Vehicle Speed Calculation
Engineering equations include:
    overall gear ratio=gear ratio x final drive ratio
    wheel rpm=engine rpm /overall gear ratio
    tyre circumfrence=pie x tyre diameter
    vehicle speed (km/h)=wheel rpm x circumfrence x (60/1000)
