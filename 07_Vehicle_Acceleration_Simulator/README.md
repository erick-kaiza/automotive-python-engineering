This Python Project simulates the acceleration of a vehicle from rest to 100 km/h using basic vehicle dynamics and numerical time-stepping.

The model calculates the rolling resistance acting against the vehicle,determines the resulting net force,calculates acceleration using Newton's second law and then updates vehicle velocity at small time intervals.

The project demonstrates how fundamental physics equations can be converted into a simple computational simulation.

MODEL ASSUMPTIONS
This is a simplified vehicle acceleration model.The current version assumes:
Constant tractive force,constant acceleration,level road,constant rolling resistance,no aerodynamic drag,no gear changes,no engine torque curve,no tyre slip,no traction limitation,no drivetrain inertia,constant vehicle mass.

These assumptions make the model suitable for demonstrating the underlying physics and numerical simulation method.

This project demonstrates the transition from static engineering calculation to a numerical simulation.Rather than directly calculating a final answer,the program repeatedly updayes the vehicle's state over time.
